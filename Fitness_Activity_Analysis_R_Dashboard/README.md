# Fitness Activity Analysis Using R — Fixed Dashboard

## Included
- `app.R` — complete R Shiny dashboard
- `data/fitness_activity.csv` — 1,800 synthetic daily activity records
- `packages.R` — dependency installation script
- `README.md` — setup guide

## Run in VS Code
1. Extract the ZIP and open the `Fitness_Activity_Analysis_R_Dashboard` folder in VS Code.
2. Open Terminal → New Terminal.
3. Run `source("packages.R")` once.
4. Run `shiny::runApp()`.
5. Open the localhost URL shown in the terminal.

The dashboard includes responsive KPI cards, interactive charts, date/activity filters, a searchable data table, and filtered CSV export. Dataset is synthetic and for educational use only.
